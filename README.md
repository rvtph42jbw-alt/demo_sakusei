# まちの安全マップ

地域の危険箇所を地図で共有し、危険度と対応状況を管理するWebアプリです。

- 一般利用者：地図閲覧、検索・絞り込み、現在地表示、JSON書き出し
- 管理者：ログイン、地点登録・編集・削除、対応状況更新、操作履歴表示
- サーバーのSQLiteに保存。複数端末で共有し、一覧は1分ごとまたは更新ボタンで再取得
- 同時編集の上書き防止、入力検証、ログイン試行制限、CSRF対策、HttpOnlyセッションCookie
- 初期データは空です。架空の危険情報は公開しません

## 起動（Node.js 24）

```sh
npm ci
npm run admin:create
npm run build
npm start
```

管理者設定では12〜128文字のパスワードを非表示で入力します。平文では保存しません。通常のローカル起動はポート3000、データは `data/` に保存されます。

開発時は `npm run dev:server` と `npm run dev` を別のターミナルで起動します。Viteの `/api` はポート3000に転送されます。インターネットへの公開にはVite開発サーバーを使用せず、下記のDocker構成を使用してください。

```sh
npm test
npm run build
npm audit
```

## Webへの公開

具体的な手順は [DEPLOY.md](DEPLOY.md) を参照してください。Docker Compose + CaddyによるHTTPS対応です。データは名前付きボリュームに保持します。HTMLだけを静的ホスティングに置いても、登録・ログイン機能は動作しません。

## 運用上の範囲

管理者は地域の運営担当者向けの共通アカウントです。一般利用者による投稿受付、個別アカウント、承認フロー、通知、写真添付は含みません。ログイン情報は一般公開せず、担当者が交代したらパスワードを変更してください。

登録した名称・メモ・位置はすべて一般公開されます。個人名、自宅の特定につながる情報、非公開の連絡先は登録しないでください。緊急通報や公的な防災情報の代替ではありません。

地図はOpenStreetMapの標準タイルを使用します。クレジット表示を保持し、[タイル利用方針](https://operations.osmfoundation.org/policies/tiles/)に従ってください。大規模アクセスやオフライン一括取得には対応せず、必要に応じて配信サービスの変更が必要です。

SQLiteを使う単一サーバー構成です。同じボリュームを複数のアプリサーバーで共有する構成にはしないでください。DB・バックアップ・管理者ハッシュは機密ファイルとして扱い、Gitや公開ディレクトリに置かないでください。
