# 参考資料に合わせた画面遷移図

提供された「画面遷移図 (1).xlsx」の機能別シート、白い四角、黒い矢印、操作名と戻る経路の表現を参考にした版です。元の参考資料は変更していません。

- Excel：`releases/machi-safety-transition-reference.xlsx`（15シート）
- PDF：`releases/machi-safety-transition-reference.pdf`（A3横・31ページ）
- 一式：`releases/machi-safety-transition-reference.zip`

メインメニュー、地図表示、検索、地点詳細、通報、防災、お気に入り、設定、ヘルプ、管理者認証、管理者地点管理、管理者通報確認の各図を掲載しています。各機能の下には70操作を選択・確認・終了で整理しています。画面一覧には利用者向けの60画面のIDとURLを記載し、操作一覧では70操作の3段階を確認できます。

同画面の即時反映・通知・ダイアログを破線で区別しています。確認・終了の各段階を常に別ページとして数えるものではありません。

Excelはセル・結合セルと線の図形で作成し、文言を編集できます。提供資料内の別システムの画面名や個人名は転用していません。アプリの画面や動作は変更していません。

作成後、全15シートを描画してレイアウトを確認し、結合セルの重複がないこと、60画面ID・70操作IDの収録、PDFの全操作の補足文が欠けないことを検証しました。保存したExcelの再読込・描画も確認しています。Windows版Excelでの操作・印刷は未実施です。
