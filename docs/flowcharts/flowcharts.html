この資料の読み方

「終了」はその操作の目的を達成した状態です。サイト全体を閉じることではありません。「確認」は内容の閲覧・反映結果の確認も含み、実装に確認ページがない場合は独立ページとして数えません。

70組 × 3段階を、210個の独立画面と数える資料ではありません。同じURLで完結する入力・保存・通知、管理者ダイアログ、外部サイト・電話アプリは区別して記載しています。

構成

  1. 全体構成図：利用者向け60画面を8カテゴリーで掲載
  2. 共通導線とエラー・取消・外部遷移の扱い
  3. 操作別フロー：利用者向け60組と管理者向け10組

SHARED NAVIGATION / EXCEPTIONS

共通導線と分岐

共通の移動

各画面 → ロゴ・地図メニュー → 地図トップ
各画面 → メインメニュー → 検索／通報／避難情報／お気に入り
各画面 → 利用者アイコン → 設定
設定・各画面のフッター → 使い方 → ヘルプ → サイトマップ → 各機能

PCではヘッダーから管理者ページへ移動できます。モバイルでは「設定 → このサービスについて → 管理者ページ」からも開けます。

通報の入力不備・通信エラー

通報内容の確認 → 位置が未入力 → 場所選択へ戻る
通報内容の確認 → 名称・状況が未入力 → 詳細入力へ戻る
送信失敗 → 確認画面でエラー通知 → 内容を保持して再試行

許可・取消・保存エラー

現在地を選択 → 許可できた → 現在地を表示
現在地を選択 → 拒否・取得失敗 → 同画面に通知
削除確認 → キャンセル → 変更せず元の画面
端末保存が失敗 → 保存できない旨を通知 → ブラウザー設定を確認

管理者操作のエラー

認証失敗・試行制限 → ログイン画面で通知 → 再入力または待機
編集・削除の競合 → 409エラー → 再取得してやり直す
確認済み通報の再確認 → 競合エラー → 最新状態を再取得

外部への移動

気象庁・自治体・ハザードマップ・OpenStreetMapは外部サイトです。電話番号のリンクは端末の通話機能へ移り、JSON書き出しはファイルのダウンロードです。いずれも独立したアプリ内完了ページとして数えません。

オンライン地図が取得できないときは参考図を表示します。安全な避難経路の計算や避難所の開設状況の配信を行う画面はありません。
