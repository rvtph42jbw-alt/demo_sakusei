# ダウンロード

[改修済み60画面版のZIPをダウンロード](https://github.com/rvtph42jbw-alt/demo_sakusei/raw/refs/heads/codex/safety-map-60screens/releases/machi-safety-map-60screens.zip)

ZIPを展開し、`demo_sakusei/はじめに.txt` を確認してください。ソース・ビルド済みファイル・起動手順・画面一覧・検証記録を同梱しています。Node.js 24が必要です。

```sh
cd demo_sakusei
npm ci
npm start
```

依存パッケージ、データベース、管理者設定、Git履歴、実際の環境変数は含まれていません。
